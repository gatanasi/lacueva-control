# LaCueva Control

This is a legacy Point of Sale and Inventory Management system built for "La Cueva" in 2015. 
The project is kept here for historical purposes, as it was actively used in production for some time.

## Overview
Built originally for a family business, it features user management, sales control, pricing, and stock management. It represents a classic Java EE / Spring MVC web application architecture from the mid-2010s.

## Technologies Used
- **Language**: Java 11
- **Frameworks**: Spring MVC 4.2, Spring Security 4
- **ORM**: Hibernate 4
- **Database**: HSQLDB (in-memory) / MySQL
- **Frontend**: JSP, JSTL, Bootstrap 3.3, jQuery 2.1
